# потом.

Личный таск-планнер для macOS 13+ и Windows 10/11. Rust / Tauri 2, Vite, React и TypeScript. Интерфейс и поведение перенесены из [handoff](docs/features/base/handoff.zip).

## Запуск

Нужны Node.js 22.12+ и стабильный Rust. Для нативной сборки на macOS нужны Xcode Command Line Tools, на Windows — Microsoft C++ Build Tools с компонентом Desktop development with C++ и WebView2.

```sh
npm ci
npm run tauri -- dev
```

Браузерный режим для разработки и проверки:

```sh
npm run dev
```

В браузере данные хранятся в localStorage текущего адреса; в desktop-приложении — в локальной SQLite. Это отдельные хранилища. Для переноса используйте экспорт и импорт JSON в настройках.

При первом запуске пространство пустое: задач и проектов нет, все 26 достижений закрыты. Первый проект можно создать вместе с первой задачей. Обновление приложения сохраняет существующие пользовательские данные.

## Возможности

- Задачи и цветные проекты, поиск, группировки, приоритеты и чеклисты.
- Канбан с четырьмя колонками, анимированным перетаскиванием и управлением с клавиатуры.
- Плавающая кнопка поверх окон: актуальный список задач в работе и переход к задаче в основном окне. Перемещается за ручку с точками; список сворачивается крестиком или `Esc`.
- Месяц, неделя и семидневная повестка календаря.
- Большая деталка задачи и несколько Markdown-документов с визуальным редактором, исходником, оглавлением и экспортом `.md`.
- 26 достижений, светлая и тёмная темы, переключение интерфейсной лексики.
- Автосохранение, резервные копии, импорт и экспорт данных; работа без сети.

`⌘/Ctrl+K` открывает поиск, `N` создаёт задачу вне поля ввода, `Esc` закрывает верхнее окно. В редакторе `⌘/Ctrl+B`, `I`, `K` форматируют текст. В канбане `Enter` открывает карточку, `Пробел` поднимает её, стрелки влево/вправо выбирают колонку, `Пробел` или `Enter` завершают перенос, `Esc` отменяет. Анимация учитывает системную настройку уменьшения движения.

У задачи может не быть срока. Перевод в «Отложено» снимает дату; назначение даты возвращает задачу в «Создана». Завершение отмечает весь чеклист. Кнопка календаря «День» показывает семь дней начиная с выбранной даты, включая выполненные задачи.

## Данные

Место хранения базы и резервных копий показано в настройках приложения. JSON-импорт проверяется до замены текущего состояния. Экспорт содержит задачи, проекты, Markdown, настройки, метрики и полученные достижения в формате `schema: 2`; поддерживается исходный формат прототипа `potom-ui-v1`.

Перед переносом на другой компьютер экспортируйте JSON. Резервные копии и экспорт содержат ваш пользовательский текст: храните их вместе с личными документами.

## Проверка и сборка

```sh
npm run build
npm test -- --run
cargo test --workspace
npx playwright install chromium
npm run test:e2e
npm run tauri -- build
```

Нативные пакеты создаются в `target/release/bundle/`. macOS собирается на macOS, Windows — на Windows.

Workflow [desktop.yml](.github/workflows/desktop.yml) запускается по тегу `v*` и вручную через GitHub Actions. Он проверяет форматирование, production-сборку, модульные тесты и Playwright-сценарии, затем запускает Rust-тесты и собирает Windows x64 (`-setup.exe` NSIS и `.msi`) и macOS Apple Silicon / Intel (`.dmg`). При ручном запуске пакеты доступны в Artifacts.

Push тега, например `v0.1.0`, после успешных проверок и всех трёх сборок автоматически публикует [GitHub Release](https://github.com/nessai1/potom/releases) с установщиками и файлом `SHA256SUMS`. Версия тега должна совпадать с `package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`. Только отдельный шаг публикации имеет право записи в репозиторий; сборочные задачи работают с правами чтения. Пока загрузка файлов не завершена, новый релиз остаётся черновиком.

Для следующего релиза обновите версии, сохраните изменения в Git и отправьте соответствующий тег в `origin`. Запуск workflow вручную не публикует релиз. Проверить скачанные файлы на macOS можно командой `shasum -a 256 -c SHA256SUMS`, на Windows — `Get-FileHash .\имя-установщика.exe -Algorithm SHA256` с сопоставлением суммы из файла.

Локальная macOS-сборка без сертификата разработчика не проходит notarization. Для публичной поставки настройте подпись Apple/Windows в своей инфраструктуре сборки. Автоматическое обновление через сервер в этой версии не настроено.

## Структура

- `src/` — React, модель задач и представления.
- `src/components/` — деталка и Markdown-редактор.
- `src/lib/storage.ts` — desktop IPC и браузерный режим.
- `src-tauri/` — Rust, SQLite, резервные копии и нативные диалоги.
- `public/assets/` — оригинальные изображения из handoff.
- `tests/` — пользовательские сценарии в браузере.

Коты и растения — изображения из исходного пакета. Лицензии зависимостей и исходного Markdown-прототипа сохранены в проекте. Внешних аккаунтов, облачной синхронизации и интеграций нет.

Проверено 18.10.2026 на macOS arm64: production-сборка, 34 модульных теста frontend, 27 сквозных сценариев на production-сборке и 14 тестов Rust; проверены плавающий список задач, перетаскивание в нативном канбане и выход через Cmd+Q с несохранённым Markdown. Windows-сборка настроена в CI и локально на этой машине не выполнялась.
